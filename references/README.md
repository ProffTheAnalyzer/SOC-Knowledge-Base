# Technical references and evidence validation

Use primary documentation to verify platform behavior, event semantics, schemas and collection requirements. Treat a suspicious observation as a hypothesis until corroborating evidence establishes its meaning.

## Investigation and validation checklist

1. Identify the product/version, telemetry provider and audit requirements.
2. Confirm relevant event fields and supported platform behavior.
3. Distinguish an observation, hypothesis and confirmed finding.
4. Test detection logic against expected-positive and legitimate activity.
5. Document the result, assumptions, confidence and limitations.
